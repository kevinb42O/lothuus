# LOTHUUS VINTAGE logo

`lothuus-vintage-v2.png` is a transparent raster recreation of the object-letter logo in `references/reference-01-lothuus-homepage.jpg`, generated with the built-in ImageGen tool. The original reference remains unchanged.

The homepage uses this asset as its main heading. Its accessible name remains LOTHUUS VINTAGE.

The exact generation and correction prompts are preserved in `generation-prompts.txt`.
